# Liurium

Liurium is an open-source, local-first developer workspace for Windows 11. It is meant to bring projects, Markdown notes, tasks, search, and coding-agent workflows together in one desktop application. Notes stay plain Markdown files on your disk. No account, no cloud upload, no telemetry by default.

## Status

Pre-alpha. There is no usable application yet; the project foundation is being set up.

## Planned stack

Tauri 2, Rust, React, TypeScript, SQLite.
